# Fictional local example

Copy this whole folder to a scratch location. AI maintains the JSON; the user does not fill forms.
Run all six commands from `references/project-tools.md` with the copied config and fresh outputs.
The test export uses a local Python host check. No MCU simulation or compiled C coverage is claimed.
Flash target/probe/image are unknown: flash export is a handoff only and must not be run on hardware.
The shopping origin is reserved `shop.example`, with no real listings/cart access.
The checked counts demonstrate five required minus three available equals two missing units.

The initial delivery list contains only reviewed example source, materials, this guide and limits.
After generating wiring or a real firmware image, AI may add those exact files and current SHA256
hashes to `deliverables.files`. Keep the revision aligned, then create a new local ZIP.
No ZIP command publishes anything. Review content and rights before any later sharing.
