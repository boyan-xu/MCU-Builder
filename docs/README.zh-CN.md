# Build with AI MCU

**把你的想法，做成可以使用的作品。**

Build with AI MCU 提供两个 AI Skill，分别陪你完成第一个单片机项目，以及有基础之后的新作品。你不需要先学编程或电子理论才能开始；已经有一些经验时，也可以选择自己写代码或由 AI 处理。先说清楚想做什么，以及希望它怎样工作。

AI 会和你一起完善想法，结合你已有的硬件、工具和经验，选择合适的实现方式。从材料清单、可选购买链接、接线图，到代码、烧录和调试，尽量由 AI 承担技术工作，让你把注意力放在作品本身。

这里没有所有人都必须照着走的固定课程。你可以从一个简单功能开始，也可以带着自己的目标逐步实现。路线随你的实际情况调整，最终得到的，是符合你需求的作品，以及可以继续使用和修改它的资料。

## 选择适合的技能

| 技能 | 适合的人 | 代码分工 |
| --- | --- | --- |
| [Build with AI MCU](../skills/build-with-ai-mcu/SKILL.md) | MCU 零基础或刚入门 | 默认由 AI 处理代码 |
| [Develop with AI MCU](../skills/develop-with-ai-mcu/SKILL.md) | 了解基本运行和烧录，做过简单项目 | 自己写或 AI 写，可以随时调整 |

两者都可独立使用。已有记忆和当前明确需求优先，不重复测试水平或强制换入口。背景未知、需求也不明确时，用“刚入门／做过简单项目”一个简短选择即可。

## 使用方式

- **先理解你的想法。** 第一句已经说清需求，就跳过无关问答。相关记忆包括 MCU 经验、聊天偏好、学习方式和小习惯；这些信息分别使用，当前需求优先，不要求先填预算或风格问卷。
- **自然交流，及时动手。** 能用简短选项就不让你反复打字，不追着同一个问题问。跟随你的节奏，但保持在项目主线上；下一步已明确就开始做，不等长篇访谈结束。
- **优先复用已有资源。** 先检查代码、配置和已有接口能否用软件解决，再考虑新硬件。不为方便换掉适合的板子，也不拿代码反复尝试弥补真实缺少的传感器或功率驱动。优先使用已有开发和烧录工具。
- **清楚看到缺什么。** 可勾选的材料面板展示规格、数量、用途与预计新增费用。可按所在国家或地区查找购买链接，也可以买其他店铺的同规格材料。
- **看图接线。** 提供标注明确的图片和对应文字步骤。先核对准确型号，讲清少量必要原理，再按实际情况安排接线和烧录顺序。
- **有基础后自选代码分工。** 入门版默认由 AI 写代码；已有基础版可选自己写、由 AI 指导审查排错，或让 AI 实现。已知选择不重复问，也可以随时改变。同一目标已有烧录授权继续复用。
- **得到自己的作品。** 交付源码、接线资料和简短使用说明。项目保留私密还是公开分享，由你选择。

## 安装

在 GitHub 选择 **Code → Download ZIP** 下载，或运行：

```sh
git clone https://github.com/boyan-xu/build-with-ai-mcu.git
```

把需要的整个技能文件夹（`skills/build-with-ai-mcu` 或 `skills/develop-with-ai-mcu`）复制到所用 AI 工具支持的技能目录，可单独安装，也可两个都装。Codex 优先使用已设置的 `$CODEX_HOME/skills`，否则使用 `~/.codex/skills`。已有同名技能时先检查再替换；必要时刷新技能发现或开启新会话。

每个技能各维护一份适用于三种语言的指令，并自带所需资源。交流、材料面板与项目说明跟随你选择的语言。其他 AI 工具需支持这种技能格式或允许加载指令；工具能力因平台而异。

## 从你的想法开始

```text
用 $build-with-ai-mcu。我想做一个门没关时提醒我的装置。
我已有 ESP32 和 Arduino IDE，但完全没用过单片机。
先帮我想清楚它应该怎样工作，代码由你处理。
```

没方向时可以要五个适合的项目；已有材料或半成品就从那里继续。目标较难时，可以拆成相关的小步骤，但保留最初的想法。

已经有项目经验时，也可以这样开始：

```text
用 $develop-with-ai-mcu。继续我已经能运行的 STM32 工程，增加 PWM 控制。
我想自己写代码，帮我检查现有定时器配置，找出下一步最小的代码任务。
```

## 想实现另一个产品里的功能

先说明想要的具体行为。适用时，AI 检查并复用已可用的 [REA](https://github.com/morluto/rea)；只有确实需要且缺少时，才询问是否安装或接入。普通项目不需要 REA，不安装也能继续。详见[可选流程](../skills/build-with-ai-mcu/references/rea.md)。

复现成果商用或公开发布前，需要查清授权和相关权利。REA 不授予目标产品的使用权，个人学习也不等于自动获得许可。目标是根据理解独立实现功能，而不是重新分发专有代码或素材。

## 工具与边界

这两份技能覆盖零基础与简单项目经验，不是高级嵌入式课程或烧录服务。AI 需要实际可用的工具连接，才能编译、调试或访问设备。网页烧录仍需要兼容硬件、固件和本地访问能力，不能保证所有环境免安装。

必要下载会提前说明，并保护已有成果与私人凭据。编译或烧录成功不代表实物工作正常；仍需检查硬件和授权，但不对同一已授权操作反复确认。个人记忆与私有记录不会随项目发布。
