# Build with AI MCU

**把你的想法，做成可以使用的作品。**

Build with AI MCU 是一个面向单片机零基础用户的 AI Skill。你不需要先学编程或电子理论，只需要说清楚想做什么，以及希望它怎样工作。

AI 会和你一起完善想法，结合你已有的硬件、工具和经验，选择合适的实现方式。从材料清单、可选购买链接、接线图，到代码、烧录和调试，尽量由 AI 承担技术工作，让你把注意力放在作品本身。

这里没有所有人都必须照着走的固定课程。你可以从一个简单功能开始，也可以带着自己的目标逐步实现。路线随你的实际情况调整，最终得到的，是符合你需求的作品，以及可以继续使用和修改它的资料。

## 使用方式

- **先理解你的想法。** 讨论想做什么、用在哪里、怎样算完成。可用记忆帮助了解你，但当前需求优先；不用先回答预算问卷或学习理论。
- **优先复用已有资源。** 先检查现有板子、材料和软件，再建议购买或下载。适合的板子不会只是因为另一块更方便就被替换。
- **清楚看到缺什么。** 可勾选的材料面板展示规格、数量、用途与预计新增费用。可按所在国家或地区查找购买链接，也可以买其他店铺的同规格材料。
- **看图接线。** 提供标注明确的图片和对应文字步骤。先核对准确型号，讲清少量必要原理，再按实际情况安排接线和烧录顺序。
- **AI 管代码与调试。** 你描述效果、配合实物操作；AI 使用现成工具，复用同一目标的已有烧录授权，分别说明已验证结果和限制。
- **得到自己的作品。** 交付源码、接线资料和简短使用说明。项目保留私密还是公开分享，由你选择。

## 安装

在 GitHub 选择 **Code → Download ZIP** 下载，或运行：

```sh
git clone https://github.com/boyan-xu/build-with-ai-mcu.git
```

把整个 `skills/build-with-ai-mcu` 文件夹复制到所用 AI 工具支持的技能目录。Codex 优先使用已设置的 `$CODEX_HOME/skills`，否则使用 `~/.codex/skills`。已有同名技能时先检查再替换；必要时刷新技能发现或开启新会话。

三种语言共用一份[技能指令](../skills/build-with-ai-mcu/SKILL.md)，交流、材料面板与项目说明跟随你选择的语言。其他 AI 工具需支持这种技能格式或允许加载指令；工具能力因平台而异。

## 从你的想法开始

```text
用 $build-with-ai-mcu。我想做一个门没关时提醒我的装置。
我已有 ESP32 和 Arduino IDE，但完全没用过单片机。
先帮我想清楚它应该怎样工作，代码由你处理。
```

没方向时可以要五个适合的项目；已有材料或半成品就从那里继续。目标较难时，可以拆成相关的小步骤，但保留最初的想法。

- [可复用材料面板](../skills/build-with-ai-mcu/assets/parts-checklist.html)：由 AI 填入实际材料，支持聊天内展示或独立网页。平台或浏览器允许时保存进度；规格或数量改变后需重新检查。
- [面板集成说明](../skills/build-with-ai-mcu/references/checklist.md)：支持的平台可直接向 AI 发出购买链接请求，否则显示可复制的请求文字。独立网页不会暗中连接 AI 或商店。
- [低压接线示例](../skills/build-with-ai-mcu/references/uno-led/README.md)：包含经过检查的图片、接线表和一致的代码引脚，展示交付标准，不是必做的入门项目。

## 工具与边界

这是零基础入门技能，不是进阶课程或烧录服务。AI 需要实际可用的工具连接，才能编译、调试或访问设备。网页烧录仍需要兼容硬件、固件和本地访问能力，不能保证所有环境免安装。

必要下载会提前说明，并保护已有成果与私人凭据。编译或烧录成功不代表实物工作正常；仍需检查硬件和授权，但不对同一已授权操作反复确认。个人记忆与私有记录不会随项目发布。

## 检查源码

运行 `node --test tests/*.test.mjs` 检查面板逻辑和示例一致性。技能格式可用官方 [skill-creator 校验器](https://github.com/openai/skills/tree/main/skills/.system/skill-creator)检查。模拟与软件检查不能代替实物测试。
