# STMGames V1：真实的 OLED 游戏机

STM32F103C8T6、小型 OLED 和五个按键，装进黄色打印外壳，成为一台掌上游戏机。这个作品经过了**多轮讨论、制作和修改**，并非一个提示词或一次生成就完成。你负责想法、实物制作和**全部 3D 建模**；按你的说明，**应用代码全部由 GPT-6.1 Sol 完成**。第三方库和已有素材继续保留各自署名及许可证。

## 接线与供电状态

![逐线标注信号及未确认供电细节的逻辑接线图](wiring.svg)

图片表示逻辑连接，不表示实物针脚位置；请按开发板与 OLED 自身丝印识别。源码确认了 I2C 引脚和五个内部上拉输入。按键另一端接地由该配置推导，本次没有进行通断或电压测量。

| 编号 | 起点 | 终点 | 依据 |
| --- | --- | --- | --- |
| W1 | PB6 | OLED SCL | 源码 I2C1 时钟 |
| W2 | PB7 | OLED SDA | 源码 I2C1 数据 |
| W3 | 开发板 GND | OLED GND | 必需的共同参考地 |
| W4 | PB10 | 上键第一个触点 | 源码输入 |
| W5 | PB11 | 下键第一个触点 | 源码输入 |
| W6 | PB12 | 左键第一个触点 | 源码输入 |
| W7 | PB13 | 右键第一个触点 | 源码输入 |
| W8 | PB14 | 确认键第一个触点 | 源码输入 |
| W9 | 开发板 GND | 每个按键的另一个触点 | 内部上拉，按下为低电平 |
| P1 | 电池正极 | 开发板 **3.3V 引脚** | 制作者提供的接法 |
| P2 | 电池负极 | 开发板 **GND 引脚** | 制作者提供的接法 |
| 待确认 | OLED VCC | 供电来源未独立确认 | 不从照片推断 |

你确认电源连接使用与烧录时相同的 **3.3V 和 GND 引脚**。这说明引脚名称，不代表两节 AA 电池能提供稳定的 3.3V。电池实际电压、开关或稳压电路、OLED VCC 及多电源之间的关系尚未核实。这份资料记录现状，不是已完成电气验证的供电方案；复刻通电前先核实这些细节，改线前断电。图中有意将 OLED VCC 留空，避免猜测。
